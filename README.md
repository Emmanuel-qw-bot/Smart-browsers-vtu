# Smart Browsers VTU

Build a new, premium, mobile-first Nigerian VTU web application called Smart Browsers.



This is a completely new project. Do not reuse any previous VendorPilot AI branding or functionality.



Brand identity



- Business name: Smart Browsers

- Short brand text: SBR 2026

- Main brand colour: elegant green.

- Supporting colours: white, dark charcoal and subtle grey.

- Design should look modern, premium, trustworthy and polished.

- Prioritise Android mobile screens while remaining fully responsive on desktop.



Initial customer experience



1. Create a short, attractive opening animation.

2. Show a green background.

3. Animate the Smart Browsers logo as though it is being handwritten.

4. Animate the text "SBR 2026" underneath.

5. Display a welcome page with the message:



"CREATE AN ACCOUNT AND GET ₦100 FREE!"



6. Provide two clear actions: Create Account and Login.



Customer dashboard structure



Prepare navigation and page layouts for:



- Dashboard

- Wallet

- Buy Data

- Buy Airtime

- Airtime to Cash

- Transactions

- Rewards

- Referrals

- Weekend Rush

- Promotions

- Notifications

- Support



Admin Control Centre structure



Create a separate, private admin dashboard with navigation for:



- Overview

- Customers

- Wallet Management

- Transactions

- VTU Provider Management

- Payment Gateway Management

- Products and Pricing

- Welcome Bonus Settings

- Referral Settings

- Loyalty Programme

- Weekend Giveaways

- Special Promotions

- Security and Activity Logs

- Reports and Profit Analysis

- Support Settings

- Platform Settings



Important development requirements



- Use reusable components and a clean project structure.

- Design the customer and admin experiences separately.

- Prepare for secure backend and database integration.

- Admin pages must be protected by real role-based access control when authentication is implemented.

- Do not expose API keys or payment credentials in frontend code.

- Do not invent successful payment, wallet funding or VTU transactions.

- Do not create fake integrations or claim that external services are connected.

- Clearly distinguish any temporary demonstration data from real data.

For this first stage, focus on the overall design, page structure, navigation and responsive layouts. Do not attempt to implement every business feature in one step.
